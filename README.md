# Dark

## Описание

Небольшой `pygame`-прототип атмосферного ASCII-рейкастера с лабиринтом, источниками света и миникартой. Проект фокусируется на визуальном ощущении глубины, освещения и перемещения по тёмному процедурному пространству.

## Возможности

- генерация лабиринта;
- ASCII-рендер кадра в реальном времени;
- освещение и туман;
- управление камерой и перемещение игрока;
- миникарта для навигации.

## Стек

- Python
- pygame

## Запуск

```bash
pip install pygame
python main.py
```
